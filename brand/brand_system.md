# ASMA-OS internal runtime identity

ASMA-OS names the internal execution fabric. It is not the customer-facing publisher brand. The customer-facing concept is FOLIAVERE, a working name pending trademark and domain clearance. See the separate customer brand rules in [brand_system.yaml](brand_system.yaml) and the shared web design tokens in [tokens.css](../apps/storefront/src/styles/tokens.css).

Use this internal identity only in founder and operations tooling. Do not use it to imply that the publishing service is launched, autonomous, or independently certified.

## Internal interface guidance

- Use the system palette and readable contrast, pairing color with status labels and icons.
- Use Inter or system sans-serif for interface text, and a monospace face for IDs and telemetry.
- Keep status, audit evidence, and approval actions distinct and easy to scan.
- Show unavailable data as unavailable; do not manufacture healthy states, financial values, or provider connectivity.
