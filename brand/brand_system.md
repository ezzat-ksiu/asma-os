# ASMA-OS Brand System

## Identity
ASMA-OS is a dependable autonomous execution fabric: clear, calm, precise, and resilient. Visual communication should make system state and operational decisions easy to scan.

## Color palette
- **Midnight navy** `#101B2D`: primary background and structural surfaces.
- **Cloud white** `#F5F7FA`: primary text and light surfaces.
- **Signal cyan** `#35C6D8`: links, active paths, and healthy system emphasis.
- **Growth green** `#42B883`: passed gates and healthy status.
- **Amber** `#F2B84B`: pending or degraded state.
- **Alert red** `#D95D5D`: failed gates and critical alerts.
- **Slate** `#718096`: secondary labels and metadata.

Use color with text or icons; never make status depend on color alone. Keep contrast readable in light and dark contexts.

## Typography
Use Inter for product interfaces and reports, with system sans-serif fallbacks. Use a clear hierarchy: bold section titles, regular body text, and monospaced labels for IDs, code, and telemetry. Body copy should remain comfortably readable (16 px / 11 pt minimum for typical screens and reports).

## Application
The wordmark is **ASMA-OS** with the descriptor **Unified Autonomous Execution Operating System**. Favor restrained geometry, consistent spacing, and legible diagrams. Avoid decorative effects that compete with system state.
